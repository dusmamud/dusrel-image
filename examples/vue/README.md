# Vue example

`App.vue` — a single-file component; `npm install @dusrel/image`
and import it anywhere. The `<dusrel-crop>` Web Component works
in Vue templates directly (register it with
`defineCropElement()` from `@dusrel/image-crop/element` and add
`dusrel-crop` to `isCustomElement` in your Vite config if Vue
warns about unknown elements). Typed wrappers
(`@dusrel/image-vue`) arrive in Phase 4.
