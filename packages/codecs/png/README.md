# @dusrel/image-png

PNG encode/decode via the Rust PNG crate (WASM, lazy-loaded). Pair with @dusrel/image-oxipng for lossless optimisation and @dusrel/image-quantize for lossy PNG.

> Status: planned — see `docs/PRD.md`, `docs/TRD.md` and `docs/ROADMAP.md` for the locked specification this package will implement.
