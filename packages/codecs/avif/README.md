# @dusrel/image-avif

libavif + libaom codec (WASM, lazy-loaded, ~3 MB — only fetched when AVIF is chosen). Default speed 9. Multi-threaded build is opt-in and needs cross-origin isolation. Vite users: exclude this package from optimizeDeps.

> Status: planned — see `docs/PRD.md`, `docs/TRD.md` and `docs/ROADMAP.md` for the locked specification this package will implement.
