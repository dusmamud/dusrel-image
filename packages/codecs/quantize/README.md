# @dusrel/image-quantize

Lossy PNG via palette quantisation with a permissive Rust quantizer (WASM). Max colours 2-256, dithering control. Engine decided 2026-11-07: libimagequant was dropped on licence grounds (GPL-3.0-or-later) so this package stays MIT — see THIRD_PARTY_LICENSES.md.
