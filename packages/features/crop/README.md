# @dusrel/image-crop

Accessible interactive crop UI built on Web Components (Cropper.js v2 model): free/fixed aspect, circle/rect, zoom/pan, keyboard support. Returns geometry only; the pipeline applies it.

> Status: planned — see `docs/PRD.md`, `docs/TRD.md` and `docs/ROADMAP.md` for the locked specification this package will implement.
