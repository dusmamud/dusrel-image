# Native codec builds

Pinned Docker build recipes for the codecs live here: Emscripten for
C/C++ (mozjpeg, webp, avif, jxl, heic) and cargo + the wasm-bindgen CLI
for Rust (one workspace under rust/: png, oxipng, resize, quantize,
qoi, gif). Never build codecs outside these images. See
docs/WASM_BUILD.md.
