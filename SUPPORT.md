# Support

- **Questions and usage help:** GitHub Discussions on this repository.
- **Bug reports:** GitHub Issues, using the bug report template. Include the
  package name and version, browser and version, a minimal reproduction and,
  if possible, a sample image (only share images you have the right to share).
- **Feature requests:** GitHub Issues, using the feature request template.
  Check `docs/ROADMAP.md` first — it may already be planned.
- **Security issues:** see `SECURITY.md`. Never report these publicly.

Please do not contact maintainers privately for general support.
